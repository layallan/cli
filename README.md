# Center of Light Intelligence Research Lab

Research group website for the Center of Light Intelligence Research Lab (CLI).

## Pages

- Home
- Team
- Research
- Publications
- Funding
- Gallery

## Local development

Requires Node.js 22.13 or later and pnpm.

```bash
pnpm install
pnpm dev
```

Run `pnpm build` for a production build and `pnpm test` for the rendered-page
check.

The four research images in `public/images/frontiers` are provisional and can
be replaced without changing the page layouts.
